# Village Weather Assistant 🌦️

## About the Project
The Village Weather Assistant is a Python-based project developed using Jupyter Notebook. It allows users to speak the name of a village and receive its current weather information.

## Features
- Recognizes a village name through voice input.
- Retrieves weather information using the OpenWeatherMap API.
- Displays the temperature and wind speed.
- Provides a spoken weather report.
- Displays the weather condition.

## Technologies Used
- Python
- Jupyter Notebook
- SpeechRecognition
- pyttsx3
- Requests
- OpenWeatherMap API

## Requirements
- Python
- Jupyter Notebook
- A working microphone
- Internet connection
- An OpenWeatherMap API key

## How to Run
1. Download or clone this repository.
2. Install the required packages using `pip install -r requirements.txt`.
3. Open `village_weather_assistant.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
5. Enter your OpenWeatherMap API key when prompted.
6. Speak the name of the village when requested.
7. View and listen to the weather report.

## Output
The assistant displays and speaks the village's temperature, wind speed, and weather condition.
